💼フリーランス レート計算機

希望年収から、必要な売上・時給・案件単価を逆算

💾 データはお使いの端末・ブラウザの中にのみ保存されます。サーバーには送信されないので、安心してご利用いただけます。
⚠️ ブラウザのデータ削除、別の端末・別のブラウザでのご利用、シークレットモードではデータが引き継げません。iPhone/iPadのSafariでは約7日間使わないと自動的に消えることがあります。重要なデータは「📤 エクスポート」ボタンからバックアップを取ることをおすすめします。
🌐 本アプリは一度読み込めばオフラインでも使えます。電波がない場所や機内モードでも、計算を行うことができます。
🚨 本ツールは税務相談ではありません。 計算結果は概算の目安であり、正確な税額・社会保険料は個人の事業状況により異なります。実際のレート設定・契約における最終判断はご自身の責任でお願いいたします。 具体的な相談は税理士・社労士等の専門家にご確認ください。

📐 計算式

必要総売上 = ( 希望年収 + 年間経費 − 控除 × 税率 ) ÷ ( 1 − 税率 )

年間実働時間 = 年間稼働日数 × 1日の稼働時間 × ( 1 − 非稼働率 )

必要時給 = 必要総売上 ÷ 年間実働時間

必要日給 = 必要時給 × 1日の稼働時間 / 月額売上 = 必要総売上 ÷ 12
