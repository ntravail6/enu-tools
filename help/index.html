ホーム画面への追加方法

本アプリをホーム画面に追加すると、アプリのようにすぐ起動できます。お使いの端末を選んで手順をご確認ください。

📝 操作手順（iPhone）iOS / Safari・Chrome

  1. Safari または Chrome でこのページを開きます。
  2. 共有ボタン（□から↑が出ているアイコン）をタップします。
    ※ Safariは画面下、Chromeはアドレスバー右にあります
  3. メニューを下にスクロールし、「ホーム画面に追加」 をタップします。
  4. アプリ名を確認して、右上の 「追加」 をタップしたら完了です。
💡 ヒントChrome の「ホーム画面に追加」機能は iOS 16.4 以降で利用できます。iPhone・iPad の OS バージョンが古い場合は Safari からの追加をおすすめします。

📝 操作手順（Android）Android / Chrome

  1. Chrome でこのページを開きます。
  2. 画面右上の メニューボタン（縦に点が3つ並んだアイコン ⋮）をタップします。
  3. メニューから 「ホーム画面に追加」 または 「アプリをインストール」 を選びます。
  4. 名前を確認して 「追加」 または 「インストール」 をタップしたら完了です。
💡 ヒント機種やブラウザのバージョンによって表示が少し異なる場合があります。「ホーム画面」「インストール」のいずれかの言葉を探してみてください。
⇄

保存版の選び方・切り替え方ローカル保存版とGoogle保存版

本アプリは ローカル保存版 と Google保存版 の2つから、データの保存方法を選べます。最初の画面でお好きな方を選んでください。あとから切り替えることもできます。

📌 2つの違い

📄

ローカル保存版

ログイン不要・この端末内に保存

☁️

Google保存版

Googleドライブに保存・複数端末で同期

📝 どちらを選べばいい？

  1. サッと手軽に使いたい／ログインしたくない／1つの端末で使う → ローカル保存版 がおすすめです。
  2. データを長く大切に残したい／スマホとPCなど複数の端末で使いたい → Google保存版 がおすすめです。

📝 保存版を切り替えるには

  1. アプリ画面の右上にある 「🔄 切替」 または 「🔓 ログアウト」 ボタンをタップします。
  2. 確認メッセージが表示されるので OK を選びます。
  3. 最初の選択画面に戻るので、使いたい保存版を選び直します。
💡 安心ポイント2つの保存版のデータは それぞれ独立して保管 されます。切り替えても、もう一方のデータが消えることはありません。元の保存版を選び直せば、そのデータがそのまま表示されます。
⚠️ ご注意保存版を切り替えても、データは自動では引っ越しません。データを移したい場合は、💾 データのバックアップ・復元方法（エクスポート／インポート）をご利用ください。
📄

ローカル保存版のデータについてこの端末・ブラウザ内に保存するタイプ

ローカル保存版では、入力したデータが お使いの端末・ブラウザの中だけ に保存されます。サーバーには送信されないので、手軽でプライバシーも安心です。

📌 データの特徴

📱

この端末だけ

他の端末とは同期されません

🔒

サーバー送信なし

運営からは見えません

⚡

ログイン不要

開いてすぐ使えます

⚠️ データが消えてしまう条件以下の操作・状況では、保存したデータが消えたり読めなくなることがあります：
・ブラウザの「履歴・キャッシュ・サイトデータ」を削除した
・シークレットモード／プライベートブラウズで使った
・別のブラウザや別の端末で開いた
・端末を変えた（機種変更など）

📝 大切なデータを守るには

消えてしまうと困るデータは、こまめにバックアップを取っておくと安心です。

  1. ページ最下部のツールバーから 📤 エクスポート ボタン（小スクエア版では「出力」）をタップします。
  2. JSONファイルが保存されるので、メールやクラウドに保管しておきます。
  3. 復元したいときは 📥 インポート ボタン（小スクエア版では「読込」）から読み込みます。
💡 ヒント長く使いたいデータや、複数の端末で使いたいデータは ☁️ Google保存版 に切り替えるのもおすすめです。切り替え方は ⇄ 保存版の選び方・切り替え方 をご覧ください。
💾

データのバックアップ・復元方法（エクスポート／インポート）

本アプリのデータは お使いの端末内（ローカル） または Googleドライブ に保存されます。JSONファイルを使ってデータを保存・復元することができます。

📌 こんなときに使えます

🗓️

定期的なバックアップ

こまめに保存して安心

📱

機種変更のとき

新端末にデータを引き継ぐ

🔄

別の端末でも使う

同じデータを複数端末で

📝 操作手順

バックアップ

データを保存する（エクスポート）

  1. 本アプリを開きます。
  2. ページ最下部のツールバーを表示します。
  3. 📤 エクスポート ボタン（小スクエア版では「出力」）をタップします。
  4. JSONファイルが保存されます。メールやクラウド（Google Drive・iCloudなど）に保存しておくと安心です。
復元

データを読み込む（インポート）

  1. 本アプリを開きます。
  2. ページ最下部のツールバーを表示します。
  3. 📥 インポート ボタン（小スクエア版では「読込」）をタップします。
  4. 保存しておいたJSONファイルを選んで読み込みます。
⚠️ ご注意JSONファイルは大切なデータです。クラウドや別の場所にもバックアップを取っておくことをおすすめします。機種変更の際は、新端末にインポートが完了するまで旧端末のデータは消さないでください。
💡 ヒントインポートを行うと、現在のデータが上書きされます。心配な場合は、先に現在のデータをエクスポートしておきましょう。
📄

PDF出力方法

表示中の内容をPDFファイルとして保存できます。保存したPDFはメールやクラウドに共有・印刷などに使えます。

📝 操作手順

  1. ページ最下部のツールバーから 📄 PDF出力 ボタン（小スクエア版では「PDF」）をタップします。
  2. 印刷ダイアログが開きます。
  3. 出力先（プリンター選択）で 「PDFとして保存」 を選びます。
    ※ 端末によって「PDFに保存」「PDFで保存」など表記が異なります
  4. 保存場所を選んで 「保存」 をタップしたら完了です。
💡 ヒントiPhoneでは保存後「ファイル」アプリ、Androidでは「Files」や「Drive」などから保存したPDFを確認できます。
💡 ヒント用紙サイズを変えると見え方が変わります。A4・B5など、お好みに合わせて選んでください。
🖨

印刷方法

表示中の内容をプリンターで印刷できます。あらかじめ端末がプリンターと接続されている必要があります。

📝 操作手順

  1. ページ最下部のツールバーから 🖨 印刷 ボタンをタップします。
  2. 印刷ダイアログが開きます。
  3. 使用する プリンター を選びます。
  4. 必要に応じて部数・用紙サイズなどを設定します。
  5. 「印刷」 をタップしたら完了です。
⚠️ ご注意事前にプリンターの電源と接続をご確認ください。スマホからの印刷には、iPhoneは AirPrint 対応プリンター、Androidは クラウド印刷 対応プリンターが必要です。
💡 ヒントプリンターがない環境では、代わりに 📄 PDF出力（小スクエア版では「PDF」）でPDFに保存し、後で印刷することもできます。
🔗

シェア方法

このアプリのURLを、LINEやメール・SNSなどで他の人にシェア（共有）できます。

📝 操作手順

  1. ページ最下部のツールバーから 🔗 シェア ボタンをタップします。
  2. シェアメニュー（共有シート）が開きます。
  3. シェアしたい アプリや相手 を選んだら完了です。
💡 ヒントパソコンなどシェアメニューに対応していない環境では、代わりに URLが自動でクリップボードにコピー されます。そのままメールやチャットに貼り付けてご利用ください。
⚠️ ご注意シェアされるのはアプリのURLです。あなたの入力したデータはシェアされません。データを引き継ぎたい場合は 💾 データのバックアップ・復元方法 をご利用ください。
☁️

Googleドライブ版アプリのデータについて家計簿・売上・在庫など、Googleでログインするアプリ

本アプリは、入力したデータを ご自身のGoogleドライブ に保存する仕組みです。運営者（enu）はあなたのデータを一切見ることができません。

📌 データはどこに保存されている？

📁

あなた専用のシート

Drive内にアプリごとに作成

🔒

運営からは見えない

技術的にアクセス不可

🌐

端末を変えてもOK

同じGoogleアカウントで継続

💡 安心ポイント本アプリが要求する権限は 「このアプリが作成したファイルだけ」 へのアクセスです。あなたのGoogleドライブの他のファイルや個人情報には一切アクセスできない設計です。

▶ データのバックアップを取る

大切なデータは定期的にコピーしておくと安心です。

  1. Googleドライブ を開きます。
  2. 該当のスプレッドシート（例：test-tools-hhk-kakeibo_data）を開きます。
  3. メニューの ファイル → コピーを作成 をクリックします。
  4. ファイル名を 「kakeibo_backup_20260515」 のように日付入りで保存します。
    ※ アプリで使うファイルとは別名にするのが大事。元の名前のままだと、アプリが間違ってバックアップ側を読みに行く可能性があります。

▶ うっかり壊した・編集してしまった時の復元

Googleスプレッドシートには変更履歴が自動で残っているので、過去の状態に戻せます。

  1. 該当のスプレッドシートを開きます。
  2. メニューの ファイル → 変更履歴 → 変更履歴を表示 をクリックします。
  3. 左の一覧から、戻したい時点のバージョンを選びます。
  4. 画面上部の 「このバージョンを復元」 をクリックします。

▶ 機種変更・別の端末で使う

特別な引き継ぎ操作は必要ありません。

  1. 新しい端末（PC・スマホ）で本アプリのURLを開きます。
  2. 同じGoogleアカウントでログインします。
  3. これまでのデータがそのまま表示されます。

▶ データが見当たらない・空に見える

よくある原因と対処法：

  1. 別のGoogleアカウントでログインしているかも → 画面右上などで現在のアカウントを確認、必要なら切り替えて再ログインしてください。
  2. 誤ってファイルを削除したかも → Driveの ゴミ箱 を確認、あれば復元してください。
  3. スプレッドシートのタブ名を変えてしまったかも → タブ名を Sheet1（半角S大文字）に戻してください。

▶ アプリの利用をやめたい

  1. 不要なら、Drive上のスプレッドシートを削除（または別の場所に保管）します。
  2. Googleアカウントのアクセス権設定 を開きます。
  3. 本アプリの名前を探して、「アクセス権を削除」 をクリックします。
⚠️ スプレッドシートを直接編集するときの注意値の修正や、1行まるごとの削除は安全です。ただし以下を行うとアプリが正しく動作しなくなります：
・列の追加／削除／並べ替え
・「Sheet1」タブの名前変更・削除
・1行目（ヘッダー行）の削除
壊してしまっても上記の「変更履歴」から戻せるので、心配しすぎなくても大丈夫です。
🔐

ログインがうまくいかないときポップアップ／通信エラー／許可の問題

本アプリで Googleドライブにデータを保存 する設定にしている場合は、Googleでのログインが必要です。ログインが進まない・エラーが出るときは、以下を順番にお試しください。

① ログインボタンを押しても何も起きない

ブラウザの「ポップアップブロック」が原因の可能性があります。お使いのブラウザに合わせて解除してください。

▶ Chrome（PC・スマホ共通）

  1. アドレスバー右側の 🚫マーク（ポップアップがブロックされたアイコン）をタップ／クリックします。
  2. 「このサイトのポップアップとリダイレクトを常に許可する」 を選択します。
  3. ページを再読み込みしてから、もう一度ログインボタンを押します。

▶ Safari（iPhone・iPad）

  1. iPhoneの 「設定」 アプリを開きます。
  2. 下にスクロールして 「Safari」 をタップします。
  3. 「ポップアップブロック」 のスイッチをオフにします。
  4. 本アプリのページに戻って再読み込みしてから、もう一度ログインボタンを押します。

▶ Safari（Mac）

  1. Safariメニュー → 設定 → Webサイト タブを開きます。
  2. 左メニューから ポップアップウィンドウ を選択します。
  3. 本アプリのドメインを 「許可」 に変更します。
  4. ページを再読み込みしてから、もう一度ログインボタンを押します。

② ログイン後に「通信エラー」と表示される

  1. ページを再読み込みしてみます。
    ※ PCは Ctrl+R／Mac は Cmd+R
  2. 解決しない場合、ブラウザの シークレットウィンドウ／プライベートブラウズ で開いてみます。
  3. それでもダメな場合、別のブラウザ（Chrome → Safari など）で試してみます。
  4. インターネット接続を確認します。

③ 誤って「許可しない」を押してしまった

  1. Googleアカウントのアクセス権設定ページ を開きます。
  2. 本アプリの名前を探してタップします。
  3. 「アクセス権を削除」 をクリックします。
  4. 本アプリのページに戻り、もう一度ログインボタンを押します。今度は同意画面が再度表示されます。
💡 安心ポイント本アプリが要求する権限は 「このアプリが作成したファイルだけ」 へのアクセスです。あなたのGoogleドライブの他のファイルや個人情報は一切見ることができない設計です。

④ それでも解決しないとき

恐れ入りますが、お使いの環境（OS・ブラウザ）とエラーの状況を添えて、下記までお知らせください。
