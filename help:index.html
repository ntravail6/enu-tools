ホーム画面への追加方法

本アプリをホーム画面に追加すると、アプリのようにすぐ起動できます。お使いの端末を選んで手順をご確認ください。

📝 操作手順（iPhone）iOS / Safari・Chrome

  1. Safari または Chrome でこのページを開きます。
  2. 共有ボタン（□から↑が出ているアイコン）をタップします。
    ※ Safariは画面下、Chromeはアドレスバー右にあります
  3. メニューを下にスクロールし、「ホーム画面に追加」 をタップします。
  4. アプリ名を確認して、右上の 「追加」 をタップしたら完了です。
💡 ヒントChrome の「ホーム画面に追加」機能は iOS 16.4 以降で利用できます。iPhone・iPad の OS バージョンが古い場合は Safari からの追加をおすすめします。

📝 操作手順（Android）Android / Chrome

  1. Chrome でこのページを開きます。
  2. 画面右上の メニューボタン（縦に点が3つ並んだアイコン ⋮）をタップします。
  3. メニューから 「ホーム画面に追加」 または 「アプリをインストール」 を選びます。
  4. 名前を確認して 「追加」 または 「インストール」 をタップしたら完了です。
💡 ヒント機種やブラウザのバージョンによって表示が少し異なる場合があります。「ホーム画面」「インストール」のいずれかの言葉を探してみてください。

データのバックアップ・復元方法（エクスポート／インポート）

本アプリのデータはお使いの端末内に保存されています。JSONファイルを使ってデータを保存・復元できます。

📌 こんなときに使えます

🗓️

定期的なバックアップ

こまめに保存して安心

📱

機種変更のとき

新端末にデータを引き継ぐ

🔄

別の端末でも使う

同じデータを複数端末で

📝 操作手順

バックアップ

データを保存する（エクスポート）

  1. 本アプリを開きます。
  2. ページ最下部のツールバーを表示します。
  3. 📤 エクスポート ボタン（小スクエア版では「出力」）をタップします。
  4. JSONファイルが保存されます。メールやクラウド（Google Drive・iCloudなど）に保存しておくと安心です。
復元

データを読み込む（インポート）

  1. 本アプリを開きます。
  2. ページ最下部のツールバーを表示します。
  3. 📥 インポート ボタン（小スクエア版では「読込」）をタップします。
  4. 保存しておいたJSONファイルを選んで読み込みます。
⚠️ ご注意JSONファイルは大切なデータです。クラウドや別の場所にもバックアップを取っておくことをおすすめします。機種変更の際は、新端末にインポートが完了するまで旧端末のデータは消さないでください。
💡 ヒントインポートを行うと、現在のデータが上書きされます。心配な場合は、先に現在のデータをエクスポートしておきましょう。

PDF出力方法

表示中の内容をPDFファイルとして保存できます。保存したPDFはメールやクラウドに共有・印刷などに使えます。

📝 操作手順

  1. ページ最下部のツールバーから 📄 PDF出力 ボタン（小スクエア版では「PDF」）をタップします。
  2. 印刷ダイアログが開きます。
  3. 出力先（プリンター選択）で 「PDFとして保存」 を選びます。
    ※ 端末によって「PDFに保存」「PDFで保存」など表記が異なります
  4. 保存場所を選んで 「保存」 をタップしたら完了です。
💡 ヒントiPhoneでは保存後「ファイル」アプリ、Androidでは「Files」や「Drive」などから保存したPDFを確認できます。
💡 ヒント用紙サイズを変えると見え方が変わります。A4・B5など、お好みに合わせて選んでください。
🖨

印刷方法

表示中の内容をプリンターで印刷できます。あらかじめ端末がプリンターと接続されている必要があります。

📝 操作手順

  1. ページ最下部のツールバーから 🖨 印刷 ボタンをタップします。
  2. 印刷ダイアログが開きます。
  3. 使用する プリンター を選びます。
  4. 必要に応じて部数・用紙サイズなどを設定します。
  5. 「印刷」 をタップしたら完了です。
⚠️ ご注意事前にプリンターの電源と接続をご確認ください。スマホからの印刷には、iPhoneは AirPrint 対応プリンター、Androidは クラウド印刷 対応プリンターが必要です。
💡 ヒントプリンターがない環境では、代わりに 📄 PDF出力（小スクエア版では「PDF」）でPDFに保存し、後で印刷することもできます。
🔗

共有方法

このアプリのURLを、LINEやメール・SNSなどで他の人に共有できます。

📝 操作手順

  1. ページ最下部のツールバーから 🔗 共有 ボタンをタップします。
  2. 共有メニュー（共有シート）が開きます。
  3. 共有したい アプリや相手 を選んだら完了です。
💡 ヒントパソコンなど共有メニューに対応していない環境では、代わりに URLが自動でクリップボードにコピー されます。そのままメールやチャットに貼り付けてご利用ください。
⚠️ ご注意共有されるのはアプリのURLです。あなたの入力したデータは共有されません。データを引き継ぎたい場合は 💾 データのバックアップ・復元方法 をご利用ください。
